# Accepted design

This index records Abgleich's accepted design choices and their scope.
The area files carry the same weight as [AGENTS.md](../../AGENTS.md) for
contributors working in this repository.

Read the relevant files before proposing a change or recording a finding.
Record owner-agreed choices and tradeoffs in the owning area file.

- [Package boundaries](accepted-design/architecture.md) covers ownership,
  dependency direction, and composition.
- [GitHub automation and jobs](accepted-design/automation.md) covers job
  lifecycle, comment dispatch, merge policy, and mutation guards.
- [AI summaries](accepted-design/summaries.md) covers consent, context, and
  deduplication.
- [AI reviews](accepted-design/reviews.md) covers consent, source access,
  verdicts, history, and review-thread maintenance.
